# Клёвое место — Старобешевское водохранилище

Telegram mini app для рыбаков Старобешевского водохранилища (пгт Новый Свет). Приложение подсказывает, какую рыбу, на каком из 28 мест, на какой глубине и дистанции ловить и на какую насадку.

## Экраны

- **Подбор** — выбираете рыбу, сезон и способ ловли (берег / лодка / спиннинг) и получаете «рецепт» (глубина, дистанция, насадки, прикормка, снасть) и рейтинг подходящих мест.
- **Карта** — спутниковая карта водоёма с 28 кликабельными метками, фильтр по рыбе, зум.
- **Рыба** — справочник по 12 видам: мирная рыба и хищник.
- **Водоём** — характеристики, особенности, цены, правила и источники.

## Технологии

TanStack Start (React 19), Tailwind CSS 4, shadcn/ui, Telegram WebApp SDK, Netlify (хостинг + Image CDN).

Все данные о местах и рыбе лежат в `src/data/reservoir.ts`.

## Локальный запуск

```bash
pnpm install
pnpm dev   # http://localhost:3000
```

## Подключение к Telegram

1. В [@BotFather](https://t.me/BotFather) создайте бота (`/newbot`).
2. Выполните `/newapp` (или `/mybots → Bot Settings → Menu Button`) и укажите URL сайта: `https://starobeshevo-fishing-app.netlify.app`.
3. Откройте бота в Telegram — приложение запустится внутри чата, на весь экран, с системной кнопкой «Назад» и вибро-откликом.

Вне Telegram приложение работает как обычный мобильный сайт.
