# Клёвое место для Android

Изолированная Capacitor-оболочка для первого тестового APK. Она открывает действующий защищённый сайт и использует тот же сервер и аккаунты.

## Сборка

GitHub Actions → Build Android APK → Run workflow. Готовый APK появится в Artifacts.

## Важно

Этот этап предназначен для внутреннего тестирования. Перед публикацией в RuStore и Google Play нужно перейти к локально упакованному интерфейсу, добавить и проверить нативные возможности (в частности push-уведомления, обработку внешних ссылок и поведение при потере сети), настроить подпись релизов и подготовить store listing.
